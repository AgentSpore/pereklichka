# Перекличка — MVP

## Проблема

Около 5 млн пожилых людей в РФ живут одни. Родственники не знают, всё ли с ними в порядке, пока сами не дозвонятся. Существующие решения требуют от пожилого человека смартфона и нажатия кнопки: zabota.app, «Мои Родители», «Я_ОК». Колонку с Алисой многие семьи уже купили родителям (в 2025 году продано около 7 млн колонок, доля Яндекса 86 %). Голосом ответить «всё хорошо» проще, чем открыть приложение.

## Что делает продукт

1. Пожилой человек утром говорит колонке «Алиса, запусти Перекличку». Навык задаёт два-три вопроса: самочувствие, приняты ли лекарства, нужно ли что-нибудь.
2. Ответы уходят родственникам в Telegram-бот одним коротким отчётом.
3. Если к назначенному часу отметки нет, бот предупреждает первого родственника. Ещё через N минут предупреждает всех из списка.
4. Позже: напоминание колонкой через сценарий умного дома, режим «ребёнок пришёл домой», MAX вместо Telegram.

## Границы MVP

Входит:
- вебхук навыка Яндекс Диалогов: утренняя отметка и привязка колонки к семье по коду;
- Telegram-бот родственника: создать семью, получить код привязки, задать час отметки и список оповещения, получать отчёты и тревоги;
- планировщик тишины: проверка дедлайна раз в минуту, эскалация по цепочке;
- согласие пожилого человека на обработку данных, записанное голосом при привязке.

Не входит: оплата, MAX, Маруся и Салют, датчики, детский режим, веб-кабинет.

## Архитектура

Один сервис на Python 3.12: FastAPI, SQLAlchemy 2.0 async, PostgreSQL, aiogram 3, APScheduler. Инструменты: uv, ruff, ty, pytest с testcontainers.

| Модуль | Задача |
|---|---|
| `alice/` | вебхук `POST /alice`, разбор протокола Диалогов, сценарий отметки, ответ быстрее 3 с |
| `bot/` | Telegram-бот родственника |
| `domain/` | семья, подопечный, отметка, правило тревоги; без импорта инфраструктуры |
| `scheduler/` | поиск пропущенных отметок, эскалация |
| `db/` | модели, репозитории, миграции Alembic |

Привязка колонки. Родственник получает в боте шестизначный код со сроком 15 минут. Пожилой человек говорит «Алиса, попроси Перекличку привязать код 123456». Навык сохраняет `session.user.user_id` (или `application_id`, если пользователь не вошёл в аккаунт) за подопечным. Колонка без входа в аккаунт тоже работает. При привязке навык зачитывает согласие и записывает ответ «да».

Данные. Храним только ответы отметки, время и идентификатор колонки. Голос не записываем. Сведения о здоровье относятся к особой категории по 152-ФЗ, поэтому нужны отдельное согласие и хранение в РФ при выходе в прод. В Telegram уходит только текст отчёта.

## Проверка без колонки

- Юнит-тесты на JSON-запросы в формате протокола Диалогов, взятом из документации Яндекса.
- Интеграционные тесты на PostgreSQL в testcontainers.
- Тестовый чат в консоли Яндекс Диалогов: навык в черновике, вебхук на туннеле.
- Приложение «Яндекс» с Алисой на телефоне.

Требует живой Станции, пока не проверено: запуск навыка сценарием умного дома, распознавание слова «Перекличка» в шумной комнате.

## Открытые вопросы

- Может ли сценарий умного дома запустить навык без голоса человека. Если нет, напоминание делаем звонком или пушем родственнику.
- Товарный знак «Перекличка» в ФИПС не проверен.
- Хостинг в РФ для прода выбрать до первых живых пользователей.

## Порядок работ

1. Каркас сервиса, домен, БД, миграции.
2. Вебхук Алисы: отметка и привязка.
3. Telegram-бот родственника.
4. Планировщик тишины и эскалация.
5. Развёртывание на AgentSpore, черновик навыка в Диалогах, проверка в тестовом чате.
