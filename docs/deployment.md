# Развёртывание Переклички

Для локального стенда нужны Docker и Compose v2. Образ содержит Python 3.12
и зависимости из `uv.lock`. Процесс работает от UID 10001. Перед запуском
API применяет миграции Alembic; ошибка миграции останавливает запуск.

## Подготовка

Создайте файл пароля PostgreSQL вне репозитория. Содержимое читает контейнер,
его не нужно присылать в чат или указывать в команде. Файл должен быть доступен
UID 10001 на чтение. Compose вне Swarm монтирует файл напрямую и сохраняет
права хоста; настройте доступ через отдельную группу или ACL.

```bash
export POSTGRES_PASSWORD_PATH=/absolute/path/db-password
export SKILL_ID='replace-with-draft-skill-id'
export IMAGE_TAG='replace-with-commit-sha'
docker compose config --quiet
docker compose up -d --build --wait
curl --fail http://127.0.0.1:8000/health
docker compose exec -T app python deploy/readiness.py
```

Пароль не попадает в образ или YAML. API доступен только через loopback.
PostgreSQL не публикует порт. Именованный том `postgres_data` хранит данные
при пересоздании контейнеров. Не удаляйте этот том при обновлении.

`SKILL_ID` по умолчанию равен `preview-local`: это значение для стенда,
его нужно заменить ID навыка перед проверкой в Диалогах.

## Telegram

Токен BotFather сохраните в отдельном файле с теми же правами доступа.
Без токена стенд запускает API. Для бота подключите второй Compose-файл:

```bash
export BOT_TOKEN_PATH=/absolute/path/bot-token
docker compose -f compose.yaml -f deploy/bot.compose.yaml up -d --build --wait
```

`deploy/start.py` поддерживает `DATABASE_URL_FILE`, `BOT_TOKEN_FILE`
и `SKILL_ID_FILE`. Содержимое этих файлов становится переменными окружения
внутри процесса. Не публикуйте файлы, вывод окружения или URL подключения.

## AgentSpore

Публичный стенд должен направлять HTTPS на loopback-порт API через Caddy.
Передайте deploy-agent репозиторий, проверенный SHA, ID проекта
`c75fea22-de49-4efe-9d8b-8644e8d007c7`, Compose-файлы, пути к файлам секретов
и значение `SKILL_ID`. Порт и маршрут выбирает оператор сервера.

`POST /api/v1/agents/projects/{id}/deploy` не запускает сборку:
локальный `skill.md` платформы сообщает HTTP 501. Реальный запуск описан
в роли deploy-agent: сборка контейнеров, маршрут Caddy, проверка HTTPS,
затем обновление карточки проекта через действующий API платформы.
Уточните контракт обновления карточки перед вызовом: старые инструкции
о `/deploy` расходятся с `skill.md`.

После публикации проверьте `https://<handle>.agentspore.com/health`
и выполните `deploy/readiness.py` внутри контейнера. Проверка контейнера
включает `SELECT 1`; один ответ `/health` не доказывает доступность БД.

## Черновик в Диалогах

Создайте навык в консоли Яндекс Диалогов, укажите HTTPS-вебхук `/alice`
и его ID в `SKILL_ID`. В тестовом чате привяжите колонку кодом из бота,
подтвердите согласие, завершите отметку и проверьте отчёт в Telegram.
Отдельно проверьте тревогу при пропуске дедлайна и эскалацию родственникам.
Живую проверку и замер лимита 4,5 с фиксируйте отдельно от тестов.

## Обновление и восстановление

Сохраните текущий SHA и резервную копию PostgreSQL до обновления.
Новый образ собирайте с новым `IMAGE_TAG`; повторите запуск и проверки выше.
Для отката выберите предыдущий SHA и пересоберите образ. Миграции назад
автоматически не применяются: совместимость схемы проверяется отдельно.

Резервную копию создаёт оператор через `pg_dump`, хранит вне сервера
и периодически проверяет восстановление. Файлы с данными семьи не кладите
в репозиторий. Продакшен с живыми данными требует хостинга в РФ согласно спеке.
