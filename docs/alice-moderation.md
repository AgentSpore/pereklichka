# Алиса: повторная модерация

4 октября 2026 года · тестовый доступ опубликован и активен · сервер: `7bd5571`.
Владелец: Roman Konnov. Пересмотреть до: 10.10.2026.

Вторая модерация отклонена из-за неясного бота и одинаковой справки; опубликованная
версия разделяет помощь и возможности. После этого пользователь нажал
«Открыть Telegram-бота» в Диалогах: вместо перехода повторилось приветствие.
Точный тип запроса и причина поведения клиента не установлены.

Опубликованная правка убирает кнопку из новых ответов. В тексте остаются
[@PereklichkaAppBot](https://t.me/PereklichkaAppBot) и точная ссылка.
Откройте ссылку в тексте или скопируйте её в браузер; можно найти бота по точному
имени @PereklichkaAppBot. Голосовая подсказка называет его «Перекличка апп бот»,
латиницей без пробелов. Старый текст кнопки и события `ButtonPressed`
получают отдельную инструкцию без записи в отчёт и сохраняют текущий вопрос.
Правка опубликована 3 октября; пользователь подтвердил, что текстовые ссылки работают.
Мы самостоятельно открытие Telegram в интерфейсе не проверяли.

Ранее опубликованы [правка кнопки, PR #13](https://github.com/AgentSpore/pereklichka/pull/13)
и [разные ответы справки, PR #11](https://github.com/AgentSpore/pereklichka/pull/11).
Подробные результаты прошлых проверок сохранены в [истории исправлений](../.specs/alice-moderation.md).
Пользователь проверял приветствие, «Помощь» и «Что ты умеешь» в тестовом чате;
это не подтвердило прохождение модерации. Голос, настоящее устройство, иконка,
email и хранилище в консоли независимо не проверены.

## Доступ для модератора

Отказ 4 октября: не указаны шесть цифр для теста. Обычный код бота действует
15 минут и расходуется один раз, поэтому для отложенной проверки он не подходит.
Отдельный повторяемый доступ опубликован в версии `7bd5571` и активирован до
4 ноября 2026 года, 00:00 по Москве (UTC+3). В обычной установке он выключен по умолчанию.
Настроена отдельная тестовая семья и её единственный получатель: приватная группа владельца.
Два разных тестовых приложения завершили две отметки; два отчёта с правильным
содержанием получены только в этой группе.

Снаружи по HTTPS проверены 9 запросов к `/alice`: 8 ответов HTTP 200 и ожидаемый
HTTP 403 для чужого навыка; максимум 0,967 с при лимите 4,5 с. Код, тестовое согласие,
помощь с сохранением состояния, отказ и повторный вход работают. Локально прошли
209 тестов; lint, format и ty прошли, независимое ревью без замечаний. Регрессия гонки
подтвердила, что добавление участника ждёт коммита отчёта и не расширяет его получателей.
Живая проверка через синтетические запросы Алисы и настоящий Telegram: ещё 23 ответа
HTTP 200, максимум 0,747 с. Повтор завершения не создал лишнего отчёта за 5 секунд
наблюдения. Созданные для проверки подопечные, отметки и записи очереди удалены;
тестовая семья и её получатель сохранены. Точное время доставки не измеряли:
на каждый отчёт отводилось до 45 секунд ожидания.
Изменения: [PR #15](https://github.com/AgentSpore/pereklichka/pull/15).

Настройки задаются вместе: `MODERATION_FAMILY_ID`, `MODERATION_RECIPIENT_CHAT_ID`,
`MODERATION_UNTIL`. Дата должна содержать часовой пояс. Получатель: единственная
настроенная приватная группа с отрицательным ID; реальных участников переносить нельзя.
Семья должна быть пустой или содержать только тестовые привязки. Чужой или истёкший
неиспользованный обычный код с совпавшими цифрами блокирует включение теста.

Вставьте следующий текст в «Заметки для модератора»:

> Для проверки скажите «Привязать код 814527». Это публичный повторяемый код отдельной тестовой семьи; доступ действует до 4 ноября 2026 года, 00:00 по Москве (UTC+3). На согласие ответьте «да». Затем запустите «Семейную перекличку» снова и ответьте о самочувствии, лекарствах и просьбах. Используйте только вымышленные ответы. Отчёт получает отдельная приватная тестовая группа владельца, а не личный Telegram модератора. Доступ к реальным семьям отсутствует. Код можно использовать повторно и с другого приложения. «Помощь» объясняет команды, «Что ты умеешь» описывает возможности.

Каждому приложению создаётся свой тестовый подопечный после явного согласия.
Код не выдаётся обычным семьям даже после отключения теста. Тестовые подопечные
не участвуют в предупреждениях о пропусках. После истечения срока или отключения
новые ответы и отчёты отклоняются, включая ранее привязанные тестовые приложения.
Уже принятый отчёт может закончить доставку позже. При отзыве удалите ожидающие
тестовые сообщения перед удалением настроек; обычные семьи и их очереди сохраняются.
Действие в кабинете и голос нужно проверить отдельно.

## Настройки владельца

1. Откройте [настройки навыка](https://dialogs.yandex.ru/developer/skills/db4658a7-a61c-4032-bc20-ed06e034f053/draft/settings/main).
2. Оставьте название и единственное активационное имя «Семейная перекличка»; добавьте текст выше в «Заметки для модератора».
3. Сохраните настройки. Backend: `https://pereklichka.agentspore.com/alice`.
4. Пройдите проверки ниже в тестовом чате Диалогов; перед повторной отправкой проверьте ссылку M8, старую реплику M12, голос M11 и разные ответы M9 и M10.
5. Отправьте навык на модерацию повторно после успешной проверки.

## Проверки в тестовом чате

| Проверка | Ожидаемый ответ |
|---|---|
| M1. Первый запуск без привязки | Смысл навыка, передача ответов после согласия, команда «Привязать код» |
| M2. «Помощь» | Сценарий, команды и следующий ответ |
| M3. «Что ты умеешь» | Возможности, сценарий и следующий ответ |
| M4. Помощь при согласии | Инструкция, затем «да» или «нет»; код сохраняется |
| M5. Запуск привязанной колонки | Смысл навыка и «Как вы себя чувствуете?» |
| M6. Помощь на каждом вопросе | Тот же вопрос; продолжение без лишних отчётов |
| M7. Завершение отметки | Один отчёт в Telegram с ответами человека |
| M8. Запуск без привязки и с привязкой | Видны @PereklichkaAppBot и ссылка в тексте, новой кнопки нет; откройте ссылку или скопируйте её в браузер |
| M9. «Помощь», затем «Что ты умеешь» | Первый ответ объясняет настройку и команды, второй описывает возможности; ответы различаются |
| M10. Обе команды на каждом шаге | Ответ соответствует команде, следующий вопрос и данные сохраняются |
| M11. Голосовая подсказка на устройстве | Понятно имя «Перекличка апп бот» и поиск латиницей без пробелов; URL не зачитывается |
| M12. «Открыть Telegram-бота» со старой кнопки или как точная реплика | Короткая инструкция со ссылкой без приветствия; вопрос и ответы сохранены, новый отчёт не создан |
| M13 [v0.3]. «Привязать код 814527», затем «Помощь» | Тестовое согласие и инструкция; состояние и код сохраняются |
| M14 [v0.3]. «Нет», затем повторный ввод тестового кода | Отказ завершает сеанс без привязки; новый вход снова предлагает согласие |
| M15 [v0.3]. Проверка с двух приложений | У каждого свой тестовый подопечный; отчёты получает только приватная группа владельца |
| M16 [v0.3]. Истечение срока или отключение на локальном стенде | Новый вход и ответы уже привязанного тестового приложения закрыты; новых отчётов нет |

M13 и M14 проверены снаружи по HTTPS; M15 подтверждена двумя приложениями и двумя
настоящими отчётами в приватной группе. M16 проверена локально на PostgreSQL.
Это синтетические запросы протокола Алисы; голос и тестовый чат Диалогов отдельно
проверяет владелец.

Для M4 получите код в [боте](https://t.me/PereklichkaAppBot).
Для M6 произнесите обе команды на вопросах о самочувствии, лекарствах и просьбах.
Проверьте также выход фразой «Алиса, хватит» и запуск на настоящем устройстве.
Проверка вебхука не проверяет распознавание голоса и доступность имени навыка.

Наличие URL в JSON не подтверждает открытие Telegram в клиенте.

## Согласие и ограничения

Фраза согласия уточняет, что вопросы начинаются при запуске навыка человеком.
Её hash используется для новых привязок; существующие согласия не переписываются.
Повторная привязка из-за этой правки не требуется. Колонка не запускает разговор сама.
Политику конфиденциальности ещё нужно опубликовать до подключения реальных семей.

Основания: [требования Яндекса](https://yandex.ru/dev/dialogs/alice/doc/ru/requirements),
[протокол запросов](https://yandex.ru/dev/dialogs/alice/doc/ru/request-simpleutterance).
Настройка дополнительных интентов для текстовых команд помощи не нужна.
Если Диалоги передадут `YANDEX.HELP`, вебхук также ответит инструкцией.
Точная команда «Что ты умеешь» сохраняет свой смысл даже при таком интенте.
Готовность к повторной отправке и результат модерации проверяются отдельно.

Для каталожного описания сохраните описание возможностей и контакт, а инструкцию замените:

> Для настройки откройте Telegram-бота @PereklichkaAppBot: https://t.me/PereklichkaAppBot. Чтобы узнать порядок настройки и команды, скажите «Помощь». Чтобы узнать возможности, скажите «Что ты умеешь».
