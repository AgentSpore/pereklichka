# Алиса: повторная модерация

3 октября 2026 года · исправление кнопки опубликовано · сервер: `a155a2f`.
Владелец: Roman Konnov. Пересмотреть до: 10.10.2026.

Вторая модерация отклонена из-за неясного бота и одинаковой справки; опубликованная
версия разделяет помощь и возможности. После этого пользователь нажал
«Открыть Telegram-бота» в Диалогах: вместо перехода повторилось приветствие.
Точный тип запроса и причина поведения клиента не установлены.

Опубликованная правка убирает кнопку из новых ответов. В тексте остаются
[@PereklichkaAppBot](https://t.me/PereklichkaAppBot) и точная ссылка.
Откройте ссылку в тексте или скопируйте её в браузер; можно найти бота по точному
имени @PereklichkaAppBot. Голосовая подсказка называет его «Перекличка апп бот»,
латиницей без пробелов. Старый текст кнопки и события `ButtonPressed`
получают отдельную инструкцию без записи в отчёт и сохраняют текущий вопрос.
Правка опубликована 3 октября; открытие Telegram пользователь проверит сам.

## Настройки владельца

1. Откройте [настройки навыка](https://dialogs.yandex.ru/developer/skills/db4658a7-a61c-4032-bc20-ed06e034f053/draft/settings/main).
2. Оставьте название и единственное активационное имя «Семейная перекличка».
   Удалите «Перекличка семьи»: это имя отклонено модерацией.
3. Сохраните настройки. Backend: `https://pereklichka.agentspore.com/alice`.
4. Пройдите проверки ниже в тестовом чате Диалогов; перед повторной отправкой проверьте ссылку M8, старую реплику M12, голос M11 и разные ответы M9 и M10.
5. Отправьте навык на модерацию повторно после успешной проверки.

## Проверки в тестовом чате

| Проверка | Ожидаемый ответ |
|---|---|
| M1. Первый запуск без привязки | Смысл навыка, передача ответов после согласия, команда «Привязать код» |
| M2. «Помощь» | Сценарий, команды и следующий ответ |
| M3. «Что ты умеешь» | Возможности, сценарий и следующий ответ |
| M4. Помощь при согласии | Инструкция, затем «да» или «нет»; код сохраняется |
| M5. Запуск привязанной колонки | Смысл навыка и «Как вы себя чувствуете?» |
| M6. Помощь на каждом вопросе | Тот же вопрос; продолжение без лишних отчётов |
| M7. Завершение отметки | Один отчёт в Telegram с ответами человека |
| M8. Запуск без привязки и с привязкой | Видны @PereklichkaAppBot и ссылка в тексте, новой кнопки нет; откройте ссылку или скопируйте её в браузер |
| M9. «Помощь», затем «Что ты умеешь» | Первый ответ объясняет настройку и команды, второй описывает возможности; ответы различаются |
| M10. Обе команды на каждом шаге | Ответ соответствует команде, следующий вопрос и данные сохраняются |
| M11. Голосовая подсказка на устройстве | Понятно имя «Перекличка апп бот» и поиск латиницей без пробелов; URL не зачитывается |
| M12. «Открыть Telegram-бота» со старой кнопки или как точная реплика | Короткая инструкция со ссылкой без приветствия; вопрос и ответы сохранены, новый отчёт не создан |

Для M4 получите код в [боте](https://t.me/PereklichkaAppBot).
Для M6 произнесите обе команды на вопросах о самочувствии, лекарствах и просьбах.
Проверьте также выход фразой «Алиса, хватит» и запуск на настоящем устройстве.
Проверка вебхука не проверяет распознавание голоса и доступность имени навыка.

Наличие URL в JSON не подтверждает открытие Telegram в клиенте.

## Согласие и ограничения

Фраза согласия уточняет, что вопросы начинаются при запуске навыка человеком.
Её hash используется для новых привязок; существующие согласия не переписываются.
Повторная привязка из-за этой правки не требуется. Колонка не запускает разговор сама.
Политику конфиденциальности ещё нужно опубликовать до подключения реальных семей.

Основания: [требования Яндекса](https://yandex.ru/dev/dialogs/alice/doc/ru/requirements),
[протокол запросов](https://yandex.ru/dev/dialogs/alice/doc/ru/request-simpleutterance).
Настройка дополнительных интентов для текстовых команд помощи не нужна.
Если Диалоги передадут `YANDEX.HELP`, вебхук также ответит инструкцией.
Точная команда «Что ты умеешь» сохраняет свой смысл даже при таком интенте.
Готовность к повторной отправке и результат модерации проверяются отдельно.

Для каталожного описания сохраните описание возможностей и контакт, а инструкцию замените:

> Для настройки откройте Telegram-бота @PereklichkaAppBot: https://t.me/PereklichkaAppBot. Чтобы узнать порядок настройки и команды, скажите «Помощь». Чтобы узнать возможности, скажите «Что ты умеешь».
