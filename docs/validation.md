# Проверка MVP

Проверено 2 октября 2026 года в ветке `feature/mvp`. Код бота, очереди,
планировщика и запуска сервиса собран вместе. Живые Telegram и Яндекс Диалоги
пока не проверены.

## Автоматические проверки

Полный прогон: **106 passed, 1 warning in 17.14s**. Интеграционные тесты
используют PostgreSQL 16 с миграциями Alembic. Предупреждение относится к
устаревающему использованию `httpx` в `starlette.testclient`.
SQLAlchemy `SAWarning` в этом прогоне считается ошибкой.

`ruff check`, `ruff format --check` и `ty check` прошли. Проверено 59 файлов
форматирования. После добавления проверки наличия записи очереди её отдельный
тест повторён: **1 passed in 3.46s**.

Проверены команды через Dispatcher aiogram, доступ к семье, гонки приглашений,
транзакции отчётов, повторная доставка, восстановление очереди и ежедневные
тревоги. Завершённая отметка подавляет ожидающие тревоги. Эскалация продолжает
работать после местной полуночи до следующего дедлайна. Отдельные проверки
покрывают часовые пояса, DST и остановку активных обработчиков до закрытия БД.

Независимое ревью нашло две ошибки: утечку задач при отмене polling и потерю
эскалации через полночь. Обе воспроизведены до исправления. Повторное ревью
исправлений замечаний не нашло; проверка цитат из замечаний прошла.

## Параллельные диалоги

Тест запускает 20 семей одновременно, по два родственника в каждой.
80 измеренных запросов завершают 20 отметок; повторные последние ответы
не создают дополнительных отчётов. В очереди остаются ровно 40 заданий,
каждое адресовано родственнику своей семьи.

В итоговом локальном прогоне ASGI и PostgreSQL: **p95 0,186 с, максимум
0,190 с**. Сеть Telegram, сеть Яндекса и запуск планировщика в этот замер
не входят. Этот результат не доказывает соблюдение лимита 4,5 с в Диалогах.

Проверка чувствительна к ошибке: при отключении получателей отчёта она падает
на `0 == 40`. Полный прогон исходного кода прошёл.

## Контейнерный стенд

Образ `pereklichka:mvp-final` собран из кода приложения `7783fb0`;
процесс работает от `10001:10001`. Проверены миграция `0004`, готовность API
и запрос `SELECT 1` к PostgreSQL.

Через настоящий локальный TCP выполнен диалог Алисы из четырёх запросов,
повтор последнего ответа и отказ `403` запросу с чужим ID навыка.
Максимальное время этих запросов составило 0,031 с. В отдельном замере
20 параллельных приветствий: p95 0,269 с, максимум 0,271 с.
Замеры используют синтетические данные и не включают сеть Яндекса.

После пересоздания контейнеров БД и API сохранились одна семья, одна
завершённая отметка и два задания отчётов. Токен бота не задан,
поэтому задания не отправлены в Telegram. Планировщик запустился
и остановился без ошибок и предупреждений в журнале стенда.
Временные контейнеры и том этого стенда удалены.

## Повторить

```bash
uv sync --locked
uv run ruff check .
uv run ruff format --check .
uv run ty check
uv run pytest -q -W error::sqlalchemy.exc.SAWarning
```

Нужен работающий Docker. Для Colima перед прогоном задайте
`TESTCONTAINERS_DOCKER_SOCKET_OVERRIDE=/var/run/docker.sock`.
Запуск контейнерного стенда описан в [deployment.md](deployment.md).

## Проверка с живыми сервисами

Пока не подтверждены публичный HTTPS-стенд, доставка в настоящий Telegram,
черновик навыка и тестовый чат Диалогов. Нужны работающий доступ к серверу,
путь к файлу токена BotFather и ID навыка. Секреты не передаются в чат.
